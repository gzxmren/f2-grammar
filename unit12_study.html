Unit 12: Conjunctions and Linking Words（連接詞與連接語）

本單元學習如何用連接詞和連接語表達對比、讓步、原因、目的和結果。

12.1 對比和讓步（Contrast & Concession）

連接詞用法例句
although / though / even though讓步（+ 從句）Although it rained, we enjoyed the picnic.
despite / in spite of讓步（+ 名詞/-ing）Despite the rain, we enjoyed the picnic.
however / nevertheless對比（另起一句）It rained. However, we enjoyed the picnic.
while / whereas對比兩個事實Tom likes sports while Jerry prefers reading.

12.2 原因（Reason）

連接詞用法例句
because+ 從句She stayed home because she was sick.
because of+ 名詞She stayed home because of her illness.
since / as+ 從句（已知原因）Since you're tired, let's rest.

12.3 目的（Purpose）

連接詞用法例句
so that+ 從句I left early so that I wouldn't miss the bus.
in order to+ 不定式I left early in order to catch the bus.

12.4 結果（Result）

連接詞用法例句
so...thatso + adj/adv + thatThe box was so heavy that I couldn't lift it.
such...thatsuch + noun + thatIt was such a heavy box that I couldn't lift it.

考核要點 ✅

  1. although/though/even though + 從句；despite/in spite of + 名詞/-ing
  2. however/nevertheless 另起新句表對比
  3. because + 從句；because of + 名詞
  4. so that + 從句表目的；in order to + 不定式
  5. so + adj/adv + that；such + noun + that 表結果
