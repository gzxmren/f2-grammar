Unit 4: The Passive（被動語態）複習教材

4.1 主動 vs 被動

主動語態被動語態
重點誰做動作誰承受動作
結構主語 + 動詞 + 受詞主語 + be + 過去分詞 + (by + 施動者)
例句The cat ate the fish.The fish was eaten by the cat.

何時用被動？

  • 施動者不明確或不重要：My bike was stolen last night.
  • 強調承受者：The injured man was taken to hospital.
  • 正式/客觀語境：It is believed that the economy will improve.

4.2 各時態的被動結構

時態被動結構例句
Simple Presentam/is/are + V-ed₂English is spoken worldwide.
Present Continuousam/is/are + being + V-ed₂A road is being built.
Simple Pastwas/were + V-ed₂The letter was sent yesterday.
Past Continuouswas/were + being + V-ed₂The car was being repaired.
Present Perfecthave/has + been + V-ed₂The work has been finished.
Past Perfecthad + been + V-ed₂It had been completed.
will futurewill + be + V-ed₂The meeting will be held.
be going toam/is/are going to + be + V-ed₂It is going to be solved.
Modalsmodal + be + V-ed₂This must be finished today.

4.3 情態動詞被動式

公式：情態動詞 + be + 過去分詞

  • can → can be solved
  • must → must be finished
  • should → should be cleaned
  • may/might → may be cancelled
  • have to → has to be done
💡 記憶口訣

情態動詞被動式 = 情態動詞 + be + 過去分詞。情態動詞後面永遠用 be，不用 is/are/was/were！

4.4 have / get something done（使役被動）

結構：have / get + 受詞 + 過去分詞

意思：讓別人做某事（僱人或找人做）

  • I had my hair cut yesterday.（我去剪了頭髮）
  • She had her car repaired last week.
  • He had his wallet stolen on the bus.（遭遇不幸）
  • I need to get my phone fixed.（口語用法）
⚠️ 對比

I cut my hair.（我自己剪）vs I had my hair cut.（去理髮店剪）

考核要點 ✅

  1. 被動語態公式：be + 過去分詞（be 隨時態變化）
  2. 何時用被動：施動者不明確/不重要、強調承受者、正式書面語
  3. 各時態被動：記住 be 的時態變化
  4. 情態動詞被動：modal + be + V-ed₂
  5. have/get sth done：找人做某事
⚠️ 易錯點

• 忘記 be 動詞：✗ The window broken. → ✓ The window was broken.
• 進行式忘了 being：✗ is built now → ✓ is being built now
• 情態後誤用 is：✗ must is done → ✓ must be done
• 不及物動詞無被動：✗ was happened → ✓ happened
